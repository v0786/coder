# CODER
## Multi-AI Autonomous Coding Orchestrator

CODER is a local-first autonomous software engineering control plane.

**WHAT:** the user provides the goal.  
**HOW:** CODER determines and executes the process.

### Current status
Planning / technical-design phase. Product definition and architecture are complete; formal implementation has not started.

### V1
- Cloud AI model inference only
- Local-first control plane
- Provider-independent model abstraction
- CLI first
- Persistent state
- Multi-agent execution
- Permission-controlled tools
- Research and evidence
- Observation and verification
- Recovery and replanning
- MCP as an extension layer

### Core loop
Goal → Understand → Goal Contract → Knowledge/Capability Check → Research/Acquire → Strategy → Decision → Plan → Execution Graph → Agents → Models/Tools → Observe → Test → Verify → Evidence → Result.
