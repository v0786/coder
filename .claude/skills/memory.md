# Memory System

The memory system provides CODER with persistent memory across sessions. It uses JSON-formatted memory files with the following structure:

- **Project Identity**: name, purpose, core goal
- **Current State**: phase, objective, last work, next work
- **Architecture**: decisions, principles
- **Components**: providers, models
- **Workspace**: files, directories, build system
- **History**: completed phases
- **Known Issues**: description, impact, status
- **Discoveries**: important facts learned
- **Active Tasks**: pending/in-progress work
- **Completed Tasks**: historical record
- **Failures**: lessons learned
- **Recovery**: information
- **Next Session Context**: bootstrap info
