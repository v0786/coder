# CODER — Implementation Tasks

## Execution protocol
Understand → Inspect → Implement → Test → Verify → Document → Complete.

## Phase 0 — Foundation
Repository, package structure, shared types, configuration, logging.

## Phase 1 — Control Plane
Task manager, state machine, SQLite, events, audit, queue, orchestrator.

## Phase 2 — Goal
Goal engine, requirements, Goal Contract, Ask Engine, Goal-to-Execution.

## Phase 3 — Models
Model domain, provider interface, cloud provider, configuration, router, fallback, health.

## Phase 4 — Agents
Context, agent definition, registry, runtime, Supervisor, handoffs, dynamic agents.

## Phase 5 — Tools
Capability model/registry, tool runtime, filesystem, terminal, Git, tests.

## Phase 6 — Security
Permissions, scopes, approvals, risk, command/filesystem restrictions, secrets, security audit.

## Phase 7 — Workspace
Workspace manager, project detector, repository scanner, dependencies, repository intelligence.

## Phase 8 — Planning
Planner, strategies, Decision Engine, execution graph, scheduler.

## Phase 9 — Research
Research engine, web provider, source trust, evidence, freshness.

## Phase 10 — Memory
Working/task/project/episodic memory and retrieval.

## Phase 11 — Autonomous Execution
Execution engine, Observer, Progress, Test Strategy, Verifier, Debugger, Recovery, Escalation, loop/no-progress detection.

## Phase 12 — Change Management
ChangeSets, diff, worktrees, impact analysis, conflict manager, review, checkpoints, rollback.

## Phase 13 — MCP/Skills
Skill registry/runtime, MCP interface/registry/connection/discovery and permission integration.

## Phase 14 — Capability Acquisition
Gap analysis, research, proposal, approval, package/MCP/skill acquisition, verification.

## Phase 15 — Browser/Computer
Browser abstraction/runtime and later computer runtime.

## Phase 16 — Artifacts/Preview
Artifact manager, evidence storage, terminal/browser/diff/API preview.

## Phase 17 — Reliability
Metrics, tracing, notifications, safe stop, pause/resume, crash recovery, migrations.

## Phase 18 — Replay/Explainability
Replay, time travel, decision records, explainability.

## Phase 19 — Controlled Self-Improvement
Performance analysis, improvement proposal, isolated implementation, tests, review, approval.

## Phase 20 — CLI
Goal, status, tasks, inspect, agents, graph, research, capabilities, models, logs, artifacts, permissions, approvals, pause/resume/cancel, preview.

## Phase 21 — Autonomous CLI MVP
Real end-to-end coding task plus failure recovery and research scenarios.

## Phase 22 — VS Code
Application API, event streaming, task/agent/graph/activity/approval/diff/research/artifact/preview panels.

## Phase 23 — Advanced
Remote control, scheduling, automation, voice, mobile and advanced dashboards.

## V1 critical path
Foundation → State → Events → Orchestrator → Goal → Cloud Model → Router → Agent Runtime → Tools → Permissions → Planner → Graph → Observer → Verifier → Recovery → CLI → Alpha.
