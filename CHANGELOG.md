### Added

- Initial project structure for Phase 1 of CODER autonomous software engineering system

- ESLint and Prettier configuration for code style
- Jest testing framework with TypeScript support
- Configuration system with environment variable loading
- Structured logging foundation with multiple levels and metadata support
- Typed error hierarchy with categories for different error types
- CLI application foundation with `coder doctor` command
- Documentation files (.gitignore, .env.example, LICENSE, CHANGELOG.md)
- Development scripts for building, testing, linting, formatting, and cleaning
